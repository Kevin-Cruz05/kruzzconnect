The problem

Job searching is repetitive work wrapped around one important decision.

Candidates spend hours scanning boards, rewriting the same resume, and re-typing their history into forms. The decision that matters — is this job right for me? — gets buried under the busywork. Fully automated "mass apply" tools solve the busywork by removing the person entirely. KruzzConnect takes the other path.

Research question

How can we reduce the cognitive load, time, and frustration of modern job searching while maintaining meaningful human control over employment decisions?

Design constraints

Three rules the AI is never allowed to break.

These were set before any screen was drawn. They shape the data model, the scoring, and the flow.

Never invent qualifications

Every qualification the AI writes into a resume, cover letter, or form answer must trace back to evidence in the user's profile.

Always explain the score

A match percentage is never shown alone. It comes with the strong matches, the gaps, and how each category was weighted.

Human approves every submission

No application leaves the app without an explicit confirmation from the user — at every automation level, including Autopilot.

Master Career Profile

One profile, built on evidence instead of claims.

Rather than juggling many resumes, the user maintains a single structured profile — a LinkedIn-style professional page with no feed, likes, posts or followers. Each skill stores the evidence behind it, which is what lets the matcher decide whether a requirement is actually supported.

Profile sections: personal info, education, experience, projects, skills, certifications, portfolio, and career preferences (roles, industries, locations, salary, remote / hybrid / on-site).

Match scoring

An honest, app-specific score — not a fake ATS number.

Companies use different applicant-tracking systems, so KruzzConnect never claims to predict one. Instead, each posting is parsed into structured requirements and compared against the profile, producing an Application Match Score with a visible weighting.

Proposed weighting

Qualification ≠ company fit

Salary, location, work arrangement, industry, size and benefits are shown as facts beside the score, not folded into it. The AI informs; it doesn't decide whether a company is desirable.

Separate: Resume ATS Compatibility

A second score checks the tailored resume itself:

  • Keyword coverage & job-specific terms
  • Formatting and section structure
  • Readability
Human-in-the-loop flow

The agent prepares. The person verifies. Then, and only then, it submits.

Levels of automation

The user chooses how much the agent does.

Grounded in automation-design research: more autonomy for repetitive steps, with the approval gate fixed in place at every level.

Manual

  • AI finds jobs
  • User swipes
  • User applies manually
✓ Human submits

Assisted

  • AI tailors resume & cover letter
  • AI fills the application
  • User reviews
✓ Human submits

Autopilot

  • User sets rules — e.g. match >85%, salary >$70k, Human Factors, Phoenix or remote, no relocation
  • AI prepares qualifying applications
✓ Human approves each one
MVP roadmap
